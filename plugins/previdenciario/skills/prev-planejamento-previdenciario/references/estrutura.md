# Roteiro — parecer de planejamento previdenciário

1. **Identificação e consulta.** Cliente, data, pergunta em uma frase ("quando e por qual regra me aposento com o melhor valor?").
2. **Documentos analisados.** Lista com data de emissão (CNIS, CTPS, PPP, certidões).
3. **Diagnóstico do CNIS.** Tabela de vínculos: período | empregador/categoria | fonte | situação (ok / pendente / ausente / especial / rural). Lacunas e indicadores de pendência com a providência para cada um.
4. **Tempo e carência apurados** até a data do parecer (e até 13/11/2019, para direito adquirido), com a memória de cálculo do software anexa.
5. **Qualidade de segurado.** Última contribuição, período de graça aplicável (Lei 8.213, art. 15) e data em que se perderia.
6. **Simulação por regra.**
   | Regra | Base legal | Data de implemento | Idade | Tempo | RMI estimada |
   | --- | --- | --- | --- | --- | --- |
   | Pontos | EC 103, art. 15 | | | | |
   | Idade progressiva | EC 103, art. 16 | | | | |
   | Pedágio 50% | EC 103, art. 17 | | | | |
   | Idade | EC 103, art. 18 | | | | |
   | Pedágio 100% | EC 103, art. 20 | | | | |
   | Direito adquirido | até 13/11/2019 | | | | |
7. **Custeio e alternativas.** Contribuir como CI/facultativo (Lei 8.212, art. 21), valor do salário de contribuição, efeito de contribuir acima do mínimo sobre a média (EC 103, art. 26), indenização de períodos (Lei 8.212, art. 45-A). Comparar custo total com o ganho de RMI.
8. **Riscos.** Perda da qualidade de segurado, mudança legislativa, divergência do INSS sobre períodos especiais ou rurais, teto.
9. **Recomendação.** Cenário escolhido, data-alvo, providências em ordem (acerto do CNIS, PPP, recolhimentos), data de reavaliação.
10. **Ressalvas e validade.** Estimativa; reavaliar a cada 12 meses ou mudança de situação.

## Linguagem
O cliente lê o parecer. Recomendação primeiro, números em tabela, termos técnicos traduzidos (DER, RMI, carência, período de graça).
